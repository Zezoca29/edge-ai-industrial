# Frontend - Web Layer (Next.js + TypeScript)

Dashboard de monitoramento em tempo real com visualização de dados dos sensores industriais.

## Responsabilidades

- Dashboard com indicadores visuais em tempo real
- Conexão WebSocket para atualizações live
- Visualização de histórico de dados
- Gerenciamento de alertas
- Autenticação de usuários

## Tecnologias

- Next.js 14+
- TypeScript
- React
- Tailwind CSS
- WebSocket
- Chart.js / Recharts

## Executar

```bash
npm install
npm run dev
```
